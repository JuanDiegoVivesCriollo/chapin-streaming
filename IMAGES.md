## 🎨 Consideraciones de Diseño

### Paleta de Colores
- Primario: Rojos (#ef4444, #dc2626)
- Oscuros: #0f172a, #1e293b
- Acentos: Blancos y grises

### Overlay
Todas las imágenes de fondo tienen un overlay oscuro automático (85% opacidad) aplicado vía CSS, así que:
- Puedes usar imágenes coloridas
- El overlay las hará más oscuras automáticamente
- Asegúrate de que haya suficiente contraste

### Formato
- **JPG** para fotografías (mejor compresión)
- **PNG** para gráficos con transparencia
- **WebP** para mejor performance (opcional)

## 🔧 Optimización de Imágenes

### Antes de Agregar:
1. **Redimensiona** a las dimensiones recomendadas
2. **Comprime** usando:
   - TinyPNG (https://tinypng.com)
   - Squoosh (https://squoosh.app)
   - ImageOptim (Mac)
   - RIOT (Windows)

### Objetivo:
- Fondos: < 200KB cada uno
- Banderas: < 100KB cada uno
