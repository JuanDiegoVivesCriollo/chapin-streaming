📋 PASOS PARA EMPEZAR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  ABRIR TERMINAL (PowerShell)
   
   Presiona: Windows + X → "Terminal" o "PowerShell"


2️⃣  NAVEGAR A LA CARPETA DEL PROYECTO

   cd "c:\Users\DIEGO\Downloads\Desktop\chapin"


3️⃣  INSTALAR DEPENDENCIAS

   npm install

   ⏱️  Esto tomará 1-2 minutos...


4️⃣  INICIAR SERVIDOR DE DESARROLLO

   npm run dev

   🌐 Luego abre: http://localhost:3000


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎨 PERSONALIZACIÓN PENDIENTE:

  1. Agregar imágenes en: public/images/
     (Ver IMAGES.md para detalles)

  2. Configurar WhatsApp:
     → Editar: components/WhatsAppButton.tsx
     → Línea 6: const whatsappNumber = 'TU_NUMERO'

  3. Actualizar enlaces de descarga:
     → Editar: components/Descargas.tsx
     → Líneas 8-13: URLs de las APKs

  4. Personalizar contacto:
     → Editar: components/Footer.tsx
     → Email, teléfono, redes sociales


🚀 DEPLOY:

  Vercel (Recomendado):
    1. git init
    2. git add .
    3. git commit -m "Initial commit"
    4. Subir a GitHub
    5. Conectar en vercel.com

  Netlify / Otros:
    1. npm run build
    2. Subir carpeta "out/"


💡 TIPS:

  • El sitio funciona sin imágenes (muestra placeholders)
  • Todos los componentes son editables
  • Los colores se ajustan en tailwind.config.js
  • El sitio es 100% responsive
