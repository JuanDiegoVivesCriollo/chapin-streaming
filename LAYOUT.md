```
┌──────────────────────────────────────┐
│ MOBILE (< 768px)                     │
│ • Menú hamburguesa                   │
│ • Stack vertical                     │
│ • 1 columna en grids                 │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ TABLET (768px - 1023px)              │
│ • 2 columnas en grids                │
│ • Navegación completa                │
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ DESKTOP (>= 1024px)                  │
│ • 3-4 columnas en grids              │
│ • Layout completo                    │
│ • Todas las animaciones              │
└──────────────────────────────────────┘
```

- 🌊 Float - Animación continua
- 💫 Ping - Botón WhatsApp
- 🔽 Accordion - FAQ desplegable
- ⚡ Smooth Scroll - Navegación suave
